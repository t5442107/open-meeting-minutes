# Bundled component license files

This directory contains license texts and notices for components bundled by the application, including FFmpeg, Whisper, sherpa-onnx, uv, OpenCC converters and data, and the bundled speaker models. Runtime preparation also places the uv and imageio-ffmpeg wheel licenses and FFmpeg's `-L` report beside the platform binaries under `runtime/<platform>-<arch>/`. Model source URLs and SHA256 values are recorded in `backend/models/SOURCES.json`.
